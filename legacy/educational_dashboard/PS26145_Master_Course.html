# Inside backend/streaming/packet_flow.py (WindowManager):
class WindowManager:
    def __init__(self, window_size=5.0):
        self.window_size = window_size
        self.buckets = {}
        
    def add_packet(self, pkt):
        key = (pkt['src_ip'], pkt['dst_ip'], pkt['dst_port'])
        now = pkt['ts']
        if key not in self.buckets:
            self.buckets[key] = {'start_ts': now, 'pkts': [], 'bytes': 0}
        self.buckets[key]['pkts'].append(now)
        self.buckets[key]['bytes'] += pkt['len']

[2] key = (pkt['src_ip'], ...): Groups packets belonging to the same conversation.

09: Mathematical Detectives: Shannon Entropy, Jitter CV, and Volume Ratio

7 min
💡 1. What is it? (Real-World Analogy) 1) Shannon Entropy: Think of a shuffled deck of cards. If all cards are identical, randomness is 0. If perfectly shuffled, randomness is 8.0. Normal English text is ~3.0; encrypted stolen files are > 7.5. 2) Timing Jitter: A human clicks links with random delays (high jitter). A robot malware beacon fires like a metronome every 10 seconds (near-zero jitter).
🔍 2. In-Depth Technical Mechanics & 0-ACK Invariant

Our mathematical engine computes 3 wire-level invariants over each 5-second window: 1) Shannon Entropy H(X) = -sum(P(x) * log2(P(x))) over raw payload octets. 2) Inter-Arrival Time (IAT) Coefficient of Variation CV = sigma / mu, measuring robotic timing regularity. 3) Directional Volume Asymmetry Ratio R = Bytes_In / (Bytes_Out + 1). On a one-way wire, R -> infinity.

📊 3. System Architecture & Workflow
1. Payload Octets
Byte frequencies are counted across 256 possible byte values.
2. Entropy Calculation
Shannon formula computes randomness (0.0 to 8.0 bits/byte).
3. Timing Differences
Time deltas between consecutive packets yield mean (mu) and std (sigma).
4. 18-Feature Vector
Packed into a 1D vector: [entropy, iat_cv, pps, bps, asym_ratio...]
💻 4. Reference Implementation (PYTHON) 
import math, numpy as np
from collections import Counter

def compute_wire_math(payload_bytes, timestamps):
    # 1. Exact Shannon Entropy (0 to 8 bits/byte)
    counts = Counter(payload_bytes)
    n = len(payload_bytes)
    entropy = -sum((c/n) * math.log2(c/n) for c in counts.values()) if n > 0 else 0.0
    
    # 2. Timing Jitter (Coefficient of Variation CV)
    deltas = np.diff(timestamps) if len(timestamps) > 1 else [0.0]
    mean_iat = np.mean(deltas)
    cv = (np.std(deltas) / mean_iat) if mean_iat > 0 else 0.0
    
    return round(entropy, 4), round(float(cv), 4)
📝 5. Line-by-Line Breakdown
[1] Counter(payload_bytes): Tallies how many times each byte value (0x00 to 0xFF) appears.
[2] math.log2(c/n): Shannon formula measuring the information surprise of each byte.
[3] np.diff(timestamps): Calculates time gaps between consecutive arriving packets.
[4] np.std(deltas) / mean_iat: Computes the Coefficient of Variation (CV). Robotic beacons yield CV < 0.5.
🎯 Summary & Judge Takeaway

Shannon Entropy detects encrypted data exfiltration (H > 7.4), while IAT CV detects robotic C2 beaconing (CV < 0.5) using pure statistical mathematics.

GOLDEN VERDICT: Our math works even when payloads are fully encrypted, because encryption itself creates maximum entropy!
