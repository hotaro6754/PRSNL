# Why XGBoost?

## Tabular Data Supremacy
Network flow metadata is highly structured tabular data. Deep Learning (like Neural Networks) excels at unstructured data (images, text). For tabular data, **Gradient Boosted Decision Trees** (like XGBoost) consistently outperform Deep Learning in speed, accuracy, and explainability.
