# Machine Learning from Zero

## What is ML?
Machine Learning allows a system to learn patterns from data rather than being explicitly programmed with `if/then` rules.

## The Pipeline
1. **Features**: Measurable properties of the network (e.g., `packet_size_mean`).
2. **Labels**: The known truth (e.g., `1` for Malicious, `0` for Benign).
3. **Training**: The algorithm studies the features and labels to build a model.
4. **Validation**: Testing the model on data it has never seen to prevent *overfitting*.
